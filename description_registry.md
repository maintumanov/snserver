# Описание параметров (ключи) Registry
## Модуль DAYTIME
- `state_daytime` тип BOOL, возвращает состояние дневного времени
- `daytime` тип ТЕКСТ, возращает в виде текста, ==ДЕНЬ== или ==НЕ ДЕНЬ==

## Модуль NIGHTTIME
- `state_nighttime` тип BOOL, возвращает состояние ночного времени
- `nighttime` тип ТЕКСТ, возращает в виде текста, ==НОЧЬ== или ==НЕ НОЧЬ==

## Модуль ABSANCE
- `state_absence` тип BOOL, возвращает состояние отсутствия
- `absence` тип ТЕКСТ, возращает в виде текста, ==ОТСУТСТВИЕ== или ==ПРИСУТСТВИЕ==

## Модуль KEENETIC
- `keenetic` тип ТЕКСТ, возращает в виде текста, ==ОТСУТСТВИЕ==, ==ПРИСУТСТВИЕ==, ==НЕ ИЗВЕСТНО==

## Модуль OWNTRACKS
- `owntracks` тип ТЕКСТ, возращает в виде текста, ==ОТСУТСТВИЕ==, ==ПРИСУТСТВИЕ==, ==ПРИБЛИЖЕНИЕ==

## Модуль SECURITYALARM
- `security` тип ТЕКСТ, возращает в виде текста, ==АКТИВНА==, ==НЕ АКТИВНА==, ==ТРЕВОГА==
