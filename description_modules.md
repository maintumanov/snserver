# Описание Модулей
## Модуль QsnWebWidgetDaytime
Модуль предназначен для переключения по времени, расчтинанному на основании указаных координат восход и закат, (или через web интерфейс) статуса дневное время.
Модуль принимает и передает сигналы из сети.
~~Модуль реагирует на состояние модуля ночное время, когда наступает ночное время, дневное время становится не активным.~~

## Модуль QsnWebWidgetDoorBell
Модуль предназначен для проигрывании мелодии дверного звонка.
Модуль имеет два режима: ночной и дневной. В для каждого режима можно установить свою мелодию.
Так же модуль в ночном режиме позволяет пропускать определенное количество звонков.
